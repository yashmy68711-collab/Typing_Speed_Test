# Typing Speed Test (Python)

## About

A GUI application that measures typing speed and typing accuracy.

## Features

* Typing speed calculation
* Accuracy checking
* GUI interface
* Real-time typing test

## Tech Used

* Python
* Tkinter

## How to Run

Run the Python file and type the displayed sentence.

## Future Improvements

* Multiple sentences
* Timer countdown
* Dark mode
* Difficulty levels
